# Claude Code Demo

A demonstration repository for exploring [Claude Code](https://claude.ai/code) — Anthropic's official CLI for Claude.

## What is Claude Code?

Claude Code is an agentic coding tool that lives in your terminal, IDE, or browser. It can read and edit files, run commands, search codebases, and complete complex multi-step engineering tasks autonomously.

## Getting Started

### Installation

```bash
npm install -g @anthropic-ai/claude-code
```

### Launch

```bash
claude
```

## Key Features

- **Agentic coding** — reads, writes, and edits files across your codebase
- **Terminal integration** — runs shell commands, tests, and build tools
- **MCP support** — connect to external services via Model Context Protocol servers
- **IDE extensions** — available for VS Code and JetBrains
- **Hooks & automation** — configure automated behaviors via `settings.json`
